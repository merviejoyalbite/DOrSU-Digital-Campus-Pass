# DOrSU Digital Campus Pass

A React Native / Expo mobile application for student campus pass verification and campus gate scan logging.

## Project Description

The DOrSU Digital Campus Pass provides a digital student identification and verification system. It displays student information, campus status, student photo, and gate scan information.

## Features

- Student digital campus pass
- Student profile and identification details
- Student profile picture
- Active / suspended campus pass status
- Campus gate scan counter
- Scan counter reset function
- Student verification interface

## Technologies Used

- React Native
- Expo
- TypeScript
- JavaScript
- Git
- GitHub
